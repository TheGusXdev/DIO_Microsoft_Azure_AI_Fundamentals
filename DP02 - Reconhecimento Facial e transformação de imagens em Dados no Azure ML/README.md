# Projeto DIO - Azure AI Vision Studio

## Objetivo

Este projeto foi desenvolvido como parte do desafio prático da DIO com o objetivo de explorar os recursos de Visão Computacional disponibilizados pelo Microsoft Azure.

O laboratório teve como foco o estudo das funcionalidades de reconhecimento de texto (OCR), análise de imagens e detecção facial utilizando os serviços de Inteligência Artificial da plataforma Azure.

---

# Tecnologias Utilizadas

- Microsoft Azure
- Azure AI Vision
- Azure AI Services
- Vision Studio
- Git
- GitHub

---

# Etapas Realizadas

## 1. Criação do Recurso Computer Vision

Foi realizado o provisionamento de um recurso de Computer Vision no Microsoft Azure utilizando a camada gratuita disponibilizada pela plataforma.

Esse recurso é responsável por disponibilizar os serviços de Visão Computacional que permitem:

- Reconhecimento de texto em imagens
- Análise de conteúdo visual
- Detecção facial
- Extração de informações visuais

---

## 2. Configuração do Ambiente

Após a criação do recurso, foram realizadas as configurações necessárias para utilização dos serviços.

Durante essa etapa foi possível compreender:

- Como funcionam os recursos de IA no Azure
- A importância das assinaturas Azure
- O gerenciamento de chaves de acesso
- A utilização dos endpoints disponibilizados pela plataforma

---

## 3. Integração com o Vision Studio

O objetivo era integrar o recurso ao Vision Studio para realizar testes práticos de:

- Reconhecimento de texto (OCR)
- Análise de imagens
- Detecção facial

Entretanto, durante a execução do laboratório foram encontradas diferenças entre a documentação utilizada no curso e a interface atualmente disponibilizada pela Microsoft.

Devido às recentes atualizações da plataforma Azure AI e à migração de diversos serviços para o ecossistema Microsoft Foundry, não foi possível concluir a execução dos testes conforme demonstrado no material original.

Apesar dessa limitação, foi possível compreender toda a estrutura necessária para utilização dos serviços, bem como o processo de criação, gerenciamento e integração de recursos de Inteligência Artificial na nuvem.

---

Durante a realização deste projeto foi possível aprender:

# Conceitos Aprendidos

## Visão Computacional

Área da Inteligência Artificial responsável por permitir que sistemas computacionais interpretem e compreendam informações presentes em imagens e vídeos.

## OCR (Optical Character Recognition)

Tecnologia utilizada para identificar e converter textos presentes em imagens para texto digital.

### Exemplos:

- Leitura de documentos
- Digitalização de contratos
- Reconhecimento de placas
- Extração automática de informações

## Análise de Imagens

Processo onde algoritmos de Inteligência Artificial identificam objetos, padrões e características presentes em uma imagem.

## Detecção Facial

Técnica que permite localizar rostos humanos em imagens e vídeos.

## Azure AI Vision

Serviço da Microsoft responsável por disponibilizar funcionalidades de Visão Computacional para desenvolvedores e empresas.

# Desafios Encontrados

O principal desafio deste laboratório foi a adaptação às mudanças recentes na plataforma Azure AI.

Algumas funcionalidades e fluxos apresentados no conteúdo original do curso não correspondem exatamente à experiência atual oferecida pelos portais da Microsoft.

Mesmo assim, a atividade proporcionou uma excelente oportunidade para conhecer os serviços de Visão Computacional do Azure e entender como eles podem ser utilizados em soluções modernas baseadas em Inteligência Artificial.

---

# Conclusão

Este projeto contribuiu para o entendimento dos serviços de Visão Computacional da Microsoft, bem como do processo de criação e gerenciamento de recursos de IA no Azure.

Além do aprendizado técnico relacionado à Inteligência Artificial, o desafio reforçou a importância da documentação, do versionamento de projetos e da capacidade de adaptação às constantes evoluções das plataformas de tecnologia.
